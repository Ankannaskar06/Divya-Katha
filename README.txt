DIVYA KATHA — FREE WEBSITE STARTER

Files:
- index.html: the complete responsive website.

Preview:
- Double-click index.html to open it in your browser.

Publish free:
- Create a GitHub account at https://github.com/
- Create a new public repository, for example divya-katha
- Upload index.html to the repository root and commit the changes
- Open repository Settings > Pages
- Under Build and deployment, choose Deploy from a branch
- Select the main branch and /(root), then Save
- Wait for the published site URL shown on the Pages settings screen

Before launch:
- Replace the demo contact email and brand details.
- Add links to your own public videos.
- Publish more original, useful stories and check all facts.
- Replace the privacy note with a policy that reflects services you actually use.
- The email signup is intentionally a demo and does not collect addresses.
- The ad space is a placeholder. Ads do not show until an advertising account is approved and the ad code is installed.
